# power-of-ai-hub

One-page site for you.withthepowerof.ai.

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Local development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Output is written to `dist/`.

## Hosting

Deployed on Cloudflare Pages. Pushes to `main` trigger an automatic build and deploy.
